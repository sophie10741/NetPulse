# NetPulse: требования

Версия 1.0, октябрь 2026. Основной контекст: учебные лаборатории и малые сети.

Как читать таблицы:

- **Приоритет:** M — обязательно для версии 1.0, S — желательно, C — можно позже.
- **Статус:** ✔ сделано, ◐ частично, ✖ не сделано.
- **Проверка:** А — автотест, Р — проверено вручную, — — не проверялось.

Цепочка простая: пользовательская история (чего хочет человек) → требование (что должна делать система) → проверка.
