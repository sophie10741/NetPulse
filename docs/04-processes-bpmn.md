# NetPulse: бизнес-процессы (BPMN)

Версия 1.0, октябрь 2026.

BPMN — это стандартная нотация для схем процессов: кто что делает и в каком порядке. Здесь два процесса, оба показывают целевое состояние версии 1.0.

Как читать схемы: горизонтальные дорожки — участники (администратор и NetPulse); ромбы — развилки «да/нет»;
**оранжевым выделены шаги, которых в текущей версии ещё нет**. Номера требований записаны в поле «Documentation» каждого шага модели.

Файлы: `.svg` показываются прямо на GitHub, `.bpmn` можно открыть и править на [demo.bpmn.io](https://demo.bpmn.io/) (меню «Open») или в Camunda Modeler.

## 1. Обнаружение сети

![Процесс «Обнаружение сети»](diagrams/bpmn-discovery.svg)

Файл модели: [bpmn-discovery.bpmn](diagrams/bpmn-discovery.bpmn)

| Шаг | Кто делает | Что происходит | Требования |
|-----|------------|----------------|------------|
| Указать IP стартового устройства и ключевые слова | Администратор | Заполняет форму сканирования | FR-5 |
| Ввод корректен? | NetPulse | Проверяет IP и что слова заполнены | FR-5 |
| Показать ошибку ввода | NetPulse | Возвращает на форму с сообщением | FR-5 |
| Обойти сеть по SSH и сохранить результат | NetPulse (автоматически) | Читает имя хоста, интерфейсы и ARP-таблицу, сохраняет устройства, интерфейсы и связи | FR-6, FR-7 |
| Устройства найдены? | NetPulse | Проверяет результат обхода | FR-6 |
| Показать причину пустого результата | NetPulse | Объясняет, почему схемы нет. **Запланировано** | FR-9 |
| Показать схему и таблицу устройств | NetPulse | Главная страница | FR-10, FR-11 |
| Просмотреть схему и список устройств | Администратор | Смотрит результат | US-4, US-7 |

Внешняя система — сетевые устройства: NetPulse отправляет им команды по SSH (`hostname`, `ip a`, `arp -an`) и получает вывод.
Особые случаи: узел недоступен по SSH — его пропускают и идут дальше; сканирование уже идёт — новое не запускается.

## 2. Настройка устройства по шаблону

![Процесс «Настройка устройства по шаблону»](diagrams/bpmn-configure.svg)

Файл модели: [bpmn-configure.bpmn](diagrams/bpmn-configure.bpmn)

| Шаг | Кто делает | Что происходит | Требования |
|-----|------------|----------------|------------|
| Выбрать шаблон команды в меню устройства | Администратор | Нажимает на устройство на схеме, выбирает шаблон | FR-13 |
| Показать форму с подсказками | NetPulse | Поля шаблона и подсказки | FR-13, FR-14 |
| Заполнить параметры | Администратор | Вводит значения | US-9 |
| Параметры верны? | NetPulse | Проверяет каждое значение по типу | FR-14, NFR-2 |
| Показать итоговую команду и пояснение | NetPulse | Готовая команда и описание, что она делает. **Запланировано** | FR-17 |
| Подтвердить выполнение | Администратор | Явное «Да, выполнить» после просмотра команды. **Запланировано** | FR-17, US-10 |
| Выполнить команду по SSH | NetPulse (автоматически) | Подключается по ключу, выполняет, получает вывод | FR-15 |
| Показать результат выполнения | NetPulse | Вывод или текст ошибки | FR-15 |

Если параметры неверны, пользователь возвращается к форме: значения сохранены (кроме пароля), рядом показаны причины.
